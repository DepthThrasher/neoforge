# NeoForge

### The modern successor to Minecraft Forge

NeoForge is the community-developed successor to Minecraft Forge, focused on better APIs, faster updates, and an open governance model. The recommended modding platform for Minecraft 1.20.1 and beyond.

<br>

---

## Features

| | |
|:---|:---|
| **Modern APIs** | Rewritten and improved APIs addressing long-standing Forge limitations |
| **Faster Updates** | Quicker release cycle with more frequent snapshots and prereleases |
| **Open Governance** | Community-run project with transparent development and decision-making |
| **Forge Compatible** | Large overlap with Forge's API for easier mod porting |
